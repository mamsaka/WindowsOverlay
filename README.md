# Windows Overlay

Прозрачный оверлей на PyQt6. Занимает рабочую область экрана (не перекрывает
панель задач), всегда поверх окон, рисует снег и HTML-панели, а справа по
клику на стрелку выезжает меню настроек. Клики проходят сквозь оверлей везде,
кроме панелей, стрелки и меню.

## Установка

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python app.py
```

`Ctrl+Q` (глобально) — выход, `Ctrl+Shift+X` — переключить «Нажатие сквозь».
`$env:OVERLAY_DEBUG=1` — подробный лог.

## Меню и снег

- Стрелка у правого края открывает меню; повторный клик закрывает его.
- В меню переключатель **«Снег»**. Когда он включён, по экрану падают точки,
  покачиваясь влево-вправо.
- Меню занимает всю высоту рабочей области и прокручивается, если настроек много.
- Пока снег включён, в меню появляются:
  - переключатель **«Интерактивный снег»**;
  - **Плотность** — количество снежинок: реже … чаще;
  - **Ветер** — направление и сила: влево … вправо (центр = штиль);
  - **Скорость** — скорость падения;
  - **Качание** — амплитуда покачивания;
  - **Размер** — величина снежинок.
- Пока включён интерактивный снег, дополнительно появляются:
  - **Радиус захвата** — на сколько пикселей от курсора подхватываются снежинки;
  - **Ком** — сколько снежинок максимум прилипает к курсору;
  - **Высота вала** — максимум снежинок в столбике;
  - **Осыпание** — перепад высоты соседних столбиков, при котором вал обваливается.
  Значение каждого параметра показано справа от названия и меняется ползунком.
- Через разделитель, отдельно от снега, — переключатель **«Нажатие сквозь»**
  (включён по умолчанию). Он управляет, следует ли флаг наводки за курсором:
  включён — обычное поведение (над панелью, меню или стрелкой клики
  перехватываются, а в пустых местах оверлей прозрачен для кликов); выключен —
  `hover_flag` всегда `True`, и оверлей перехватывает клики по всей рабочей
  области, так что переключиться на другое окно кликом не получится. Вернуть
  управление можно этим же переключателем (меню открывается стрелкой) или
  глобально по `Ctrl+Shift+X`.
- **Интерактивный снег**: снежинки накапливаются у нижней кромки рабочей
  области (у панели задач) до «Высоты вала». Снежинка, которой не хватило
  места в столбике, не исчезает — она пролетает вал дальше и уничтожается
  только когда вылетит за край экрана (вниз или вбок).
  Если столбик выше соседнего на «Осыпание» снежинок и более, верхняя
  снежинка осыпается вбок, и так пока вал не станет устойчивым. Если зажать
  **левую кнопку мыши**, снежинки в пределах «Радиуса захвата» слетаются в
  комок вокруг курсора (не накладываясь, по фиксированным слотам) — как
  падающие, так и опавшие (из вала). Снежинки, которым не хватило места в
  комке («Ком»), просто продолжают спокойно падать (вал при этом не трогается).
  При отпускании кнопки комок рассыпается.
- Отпущенные снежинки летят по тем же правилам, что и обычные, но чуть иначе:
  ветер, скорость и качание умножаются на коэффициенты. Их можно править в
  меню (группа «Отпущенный снег», поля принимают только числа); по умолчанию
  ветер 1×, скорость 1.2×, качание 0.95× (`SNOW_RELEASED_WIND/SPEED/SWAY`
  в `overlay/config.py`).
- Сверху постоянно идёт поток новых снежинок: пока в воздухе меньше, чем
  задаёт «Плотность», спавнер досыпает снег сверху (по умолчанию ~150/с при
  полной плотности). Поэтому снегопад не заканчивается, даже когда снежинки
  укладываются в вал или уничтожаются. Скорость задаётся `SNOW_SPAWN_PER_SEC`
  в `overlay/config.py`.
- Если включён «Ветер», часть новых снежинок влетает не сверху, а с наветренной
  стороны: при ветре вправо — от левого края, при ветре влево — от правого.
  Чем сильнее ветер, тем больше доля боковых снежинок (при 100% — все), они
  появляются за краем экрана и втягиваются в кадр потоком
  (`SNOW_SIDE_SPAWN_DEPTH` в `overlay/config.py`).
- **Сбор на окнах** (только в интерактивном режиме): отдельный переключатель
  в меню. Когда он включён, снег ложится не только на нижнюю кромку, но и на
  верхние кромки открытых неразвёрнутых окон. Учитываются только видимые
  верхнеуровневые окна; перекрытые другими окнами участки кромки не
  засыпаются. Позиции и z-порядок окон опрашиваются периодически
  (`SNOW_WINDOW_POLL_MS`), при перемещении окна вал едет вместе с ним.
  Под переключателем два ползунка:
  - **Вал на окнах** — максимум снежинок в столбике на кромке окна
    (по умолчанию 3, `SNOW_WINDOW_PILE_MAX`);
  - **Осыпание на окнах** — перепад высоты соседних столбиков, при котором
    снег обваливается с края окна (по умолчанию 1,
    `SNOW_WINDOW_PILE_SLOPE`).
  Ограничения: отслеживается не больше `SNOW_WINDOW_MAX_SURFACES` окон,
  слишком узкие окна (уже `SNOW_WINDOW_MIN_WIDTH`) пропускаются. Ползунки
  видны только при включённом «Сборе на окнах».

## Структура

- `app.py` — точка входа
- `overlay/config.py` — панели (`ACTIVE_PANELS`), размеры меню, параметры снега
- `overlay/snow.py` — холст со снегом (падение, накопление, осыпание, захват курсором)
- `overlay/menu.py` — выезжающее меню, переключатели и ползунки
- `overlay/widgets.py` — стрелка и HTML-панель
- `overlay/window.py` — окно, отслеживание наведения, запуск
- `overlay/winapi.py` — горячая клавиша и click-through (Win32)
- `overlay/state.py` — `hover_flag`

## Добавление панели

```python
ACTIVE_PANELS = {
    "example": {
        "size": (320, 180),
        "bg": "#202638",
        "border": "#8296ff",
        "html": "<html><body><h2>Моя панель</h2></body></html>",
    },
}
```

## hover_flag

```python
from overlay import state
print(state.hover_flag)
```

Не используйте `from overlay.state import hover_flag` — так скопируется старое значение.
