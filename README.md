# Windows Overlay

Прозрачный оверлей на PyQt6. Занимает рабочую область экрана (не перекрывает
панель задач), всегда поверх окон, рисует снег, осенние листья и HTML-панели,
а справа по клику на стрелку выезжает меню настроек. Клики проходят сквозь
оверлей везде, кроме панелей, стрелки и меню.

## Установка

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск

```powershell
python app.py
```

`Ctrl+Q` (глобально) — выход, `Ctrl+Shift+X` — переключить «Нажатие сквозь».
`$env:OVERLAY_DEBUG=1` — подробный лог.

## Сборка в exe

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --windowed --onefile --name WindowsOverlay app.py
```

Готовый файл — `dist\WindowsOverlay.exe`. Рядом с ним создаётся и читается
`settings.env`, поэтому настройки снега сохраняются между запусками.

## Меню и снег

- Стрелка у правого края открывает меню; повторный клик закрывает его.
- В меню переключатель **«Снег»**. Когда он включён, по экрану падают точки,
  покачиваясь влево-вправо.
- Меню занимает всю высоту рабочей области и прокручивается, если настроек много.
- Пока снег включён, в меню появляются:
  - переключатель **«Интерактивный снег»**;
  - **Плотность** — количество снежинок: реже … чаще;
  - **Ветер** — направление и сила: влево … вправо (центр = штиль);
  - **Скорость** — скорость падения;
  - **Качание** — амплитуда покачивания;
  - **Размер** — величина снежинок.
- Пока включён интерактивный снег, дополнительно появляются:
  - **Радиус захвата** — на сколько пикселей от курсора подхватываются снежинки;
  - **Ком** — сколько снежинок максимум прилипает к курсору;
  - **Высота вала** — максимум снежинок в столбике;
  - **Осыпание** — перепад высоты соседних столбиков, при котором вал обваливается.
  Значение каждого параметра показано справа от названия и меняется ползунком.
- Через разделитель, отдельно от снега, — переключатель **«Нажатие сквозь»**
  (включён по умолчанию). Он управляет, следует ли флаг наводки за курсором:
  включён — обычное поведение (над панелью, меню или стрелкой клики
  перехватываются, а в пустых местах оверлей прозрачен для кликов); выключен —
  `hover_flag` всегда `True`, и оверлей перехватывает клики по всей рабочей
  области, так что переключиться на другое окно кликом не получится. Вернуть
  управление можно этим же переключателем (меню открывается стрелкой) или
  глобально по `Ctrl+Shift+X`.
- **Интерактивный снег**: снежинки накапливаются у нижней кромки рабочей
  области (у панели задач) до «Высоты вала». Осевший снег рисуется общей
  сплошной кучей: соседние снежинки сливаются в вал без просветов между ними,
  и только когда их поднимают курсором, они снова становятся отдельными
  частицами. Снежинка, которой не хватило
  места в столбике, не исчезает — она пролетает вал дальше и уничтожается
  только когда вылетит за край экрана (вниз или вбок).
  Если столбик выше соседнего на «Осыпание» снежинок и более, верхняя
  снежинка осыпается вбок, и так пока вал не станет устойчивым. Если зажать
  **левую кнопку мыши**, снежинки в пределах «Радиуса захвата» слетаются в
  комок вокруг курсора (не накладываясь, по фиксированным слотам) — как
  падающие, так и опавшие (из вала). Снежинки, которым не хватило места в
  комке («Ком»), просто продолжают спокойно падать (вал при этом не трогается).
  При отпускании кнопки комок рассыпается.
- **Инерция броска**: комок летит за курсором не мгновенно, поэтому у
  каждой снежинки есть своя скорость. Когда кнопку отпускают или снежинка
  выпадает из хватки, она **сохраняет эту скорость** и продолжает лететь по
  траектории (можно «швырнуть» снег в сторону или вверх), а не падает строго
  вниз. Лишняя скорость плавно затухает (`SNOW_THROW_DRAG`), и снежинка
  возвращается к обычному падению с качанием. Рывок курсора ограничен
  `SNOW_THROW_MAX`, чтобы снежинка не телепортировалась. Если курсор в момент
  отпускания стоял на месте, скорость нулевая и снег просто осыпается вниз.
- **Выпадение из хватки** — отдельный переключатель для срыва снежинок из комка.
  Если двигать курсор быстро, снежинки, отставшие от курсора больше «Поводка»,
  выпадают и летят дальше по инерции; до отпускания кнопки они снова не
  захватываются.
  За один кадр срывается не больше одной снежинки, поэтому даже резкий рывок
  не разрывает комок целиком — он редеет постепенно. Под переключателем два
  ползунка:
  - **Поводок** — насколько снежинка может отстать от курсора, px
    (по умолчанию 48, `SNOW_CLUMP_LEASH`);
  - **Следование** — скорость догона курсора, % (по умолчанию 35,
    `SNOW_FOLLOW_LERP`).
  Если выключить, комок держится за курсором даже при резких движениях.
- Отпущенные снежинки летят по тем же правилам, что и обычные, но чуть иначе:
  ветер, скорость и качание умножаются на коэффициенты. Их можно править в
  меню (группа «Отпущенный снег», поля принимают только числа); по умолчанию
  ветер 1×, скорость 1.2×, качание 0.95× (`SNOW_RELEASED_WIND/SPEED/SWAY`
  в `overlay/config.py`).
- Сверху постоянно идёт поток новых снежинок со скоростью, заданной
  «Плотностью» (по умолчанию ~150/с при полной плотности,
  `SNOW_SPAWN_PER_SEC` в `overlay/config.py`). **Лимита на количество нет:**
  спавнер не ждёт, пока освободится место, поэтому число снежинок на экране
  устанавливается само — скорость спавна × среднее время падения.
- Это **единственный** источник снега во всех режимах. При включении снега
  небо пустое, и снежинки появляются только через этот поток. Уничтожение
  снежинки (уход за экран) или укладка в вал не создают новую снежинку —
  пополнение всегда идёт сверху, а не «на месте».
- Если включён «Ветер», часть новых снежинок влетает не сверху, а с наветренной
  стороны: при ветре вправо — от левого края, при ветре влево — от правого.
  Чем сильнее ветер, тем больше доля боковых снежинок (при 100% — все), они
  появляются за краем экрана и втягиваются в кадр потоком
  (`SNOW_SIDE_SPAWN_DEPTH` в `overlay/config.py`).
- **Сбор на окнах** (только в интерактивном режиме): отдельный переключатель
  в меню. Когда он включён, снег ложится не только на нижнюю кромку, но и на
  верхние кромки открытых неразвёрнутых окон. Учитываются только видимые
  верхнеуровневые окна; перекрытые другими окнами участки кромки не
  засыпаются. Позиции и z-порядок окон опрашиваются периодически
  (`SNOW_WINDOW_POLL_MS`), при перемещении окна вал едет вместе с ним.
  Под переключателем два ползунка:
  - **Вал на окнах** — максимум снежинок в столбике на кромке окна
    (по умолчанию 3, `SNOW_WINDOW_PILE_MAX`);
  - **Осыпание на окнах** — перепад высоты соседних столбиков, при котором
    снег обваливается с края окна (по умолчанию 1,
    `SNOW_WINDOW_PILE_SLOPE`).
  Ограничения: отслеживается не больше `SNOW_WINDOW_MAX_SURFACES` окон,
  слишком узкие окна (уже `SNOW_WINDOW_MIN_WIDTH`) пропускаются. Ползунки
  видны только при включённом «Сборе на окнах».

### Осенние листья

Отдельный блок **«Осенние листья»** в меню, независимый от снега: его можно
включить как вместе со снегом, так и без него. Листья не копируют физику
снежинок — у них своя модель полёта и своя отрисовка.

- Поток новых листьев задаётся «Плотностью листвы» (по умолчанию ~14/с при
  полной плотности, `LEAVES_SPAWN_PER_SEC`). Как и у снега, **лимита на
  количество нет**: спавнер не ждёт освободившегося места, а число листьев
  на экране определяется скоростью спавна и временем их полёта.
- Лист лёгкий и сильно тормозится воздухом: падает медленно, постоянно
  покачивается в стороны (собственная фаза у каждого листа), вращается вокруг
  своей оси и **кувыркается**. `flip`-фаза сжимает лист по горизонтали, поэтому
  он по очереди поворачивается к зрителю лицом, ребром и обратной стороной —
  это и есть механика отображения объёмного кувырка.
- Цвета осенние: красный, багровый, оранжевый, янтарный, жёлтый, золотой,
  коричневый, оливковый, ржавый и тёмно-бордовый (`_PALETTE` в
  `overlay/leaves.py`). Формы тоже разные: овальный, округлый и
  кленовый (пятилопастной) лист. Каждый лист рисуется векторно: градиент от
  светлой стороны к теневой, тёмный контур, центральная жилка и боковые жилки.
- **Ветер листвы** сносит листья в сторону; при сильном ветре часть новых
  листьев влетает не сверху, а с наветренного края экрана.
- **Интерактивные листья** — отдельный переключатель. Когда он включён,
  работают все взаимодействия: ветер от курсора, нанос на нижней кромке и
  приземление на окна. Когда выключен, листья просто летят по экрану и
  исчезают за нижним краем, никуда не ложась и не реагируя на мышь.
- **Ветер от курсора**: движение мыши над оверлеем создаёт воздушный поток.
  Летящие листья рядом с курсором подталкиваются и закручиваются, а лежащие
  на дне — взлетают, если курсор движется достаточно быстро. Это отдельная
  механика, не связанная с захватом снега левой кнопкой.
- **Приземление на окна** — ползунок 0–100% (по умолчанию 35,
  `LEAF_WINDOW_CHANCE`): шанс, что пролетающий лист ляжет на верхнюю кромку
  видимого окна, как это делает снег при «Сборе на окнах». Лист проверяет
  кромку в момент пролёта; если шанс не сработал или кромка скрыта другим
  окном, он летит дальше. Листья на окнах лежат слоями
  (`LEAF_WINDOW_LEVELS`) и, как снег, слетают вниз, если окно переместили,
  закрыли, скрыли через Win+D или накрыли другим окном: поддержка исчезла —
  лист падает, а не висит в воздухе.
  Ползунок виден только при включённых «Интерактивных листьях».
- Долетев до поверхности, лист ложится: он сплющивается (виден почти
  с ребра) и **чутка продавливается/клипается в кромку** — нижняя часть уходит
  под линию поверхности, а короткая анимация сжатия за пару кадров
  «пришлёпывает» лист к ней. Листья в наносе перекрываются и лежат слоями;
  всего хранится до `LEAF_GROUND_MAX` штук, самые старые исчезают. Курсор может
  снова поднять лист из наноса.
- Ползунки блока: **Плотность листвы** (сколько листьев одновременно в воздухе),
  **Ветер листвы**, **Скорость листвы**, **Размер листвы**, **Кружение**
  (интенсивность качания и кувыркания) и **Приземление на окна**. Числовые
  значения по умолчанию — в `overlay/config.py` (`LEAVES_*`, `LEAF_*`).

## Сохранение настроек

- Все параметры снега и листвы автоматически сохраняются в `settings.env` в
  корне проекта (файл в `.gitignore`). При следующем запуске они загружаются и
  применяются.
- Кнопка **«Восстановить по умолчанию»** возвращает все параметры снега и
  листвы к значениям из `overlay/config.py` и сразу сохраняет их.
- Блок **«Функциональные настройки»** (переключатель «Нажатие сквозь») всегда
  стартует со значений по умолчанию и никуда не сохраняется.

## Структура

- `app.py` — точка входа
- `overlay/config.py` — панели (`ACTIVE_PANELS`), размеры меню, параметры снега и листвы
- `overlay/snow.py` — холст со снегом (падение, накопление, осыпание, захват курсором)
- `overlay/leaves.py` — осенние листья (своя физика, кувыркание, ветер от курсора, нанос)
- `overlay/menu.py` — выезжающее меню, переключатели и ползунки
- `overlay/settings.py` — сохранение и загрузка параметров снега и листвы (`settings.env`)
- `overlay/widgets.py` — стрелка и HTML-панель
- `overlay/window.py` — окно, отслеживание наведения, запуск
- `overlay/winapi.py` — горячая клавиша и click-through (Win32)
- `overlay/state.py` — `hover_flag`

## Добавление панели

```python
ACTIVE_PANELS = {
    "example": {
        "size": (320, 180),
        "bg": "#202638",
        "border": "#8296ff",
        "html": "<html><body><h2>Моя панель</h2></body></html>",
    },
}
```

## hover_flag

```python
from overlay import state
print(state.hover_flag)
```

Не используйте `from overlay.state import hover_flag` — так скопируется старое значение.
